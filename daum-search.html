다음 통합검색 정답형 개편

인물·장소·방송 검색은 각자 다른 구조로 운영되고 있었습니다. 디자인 리드로서 이 컬렉션들을 하나의 정보 구조와 탐색 흐름으로 통합했고, 검색 전반에 재사용할 공통 UI 기준을 만들었습니다. 지금 디자인 시스템을 다루는 방식의 뿌리가 된 작업입니다.

Year2019.03 – 2020.03
PlatformWeb · App
RoleDesign Lead
Status출시

Structure

인물·장소·방송 검색을 하나의 구조로

따로 운영되던 인물·장소·방송 검색의 정보 구조와 탐색 동선을 개편했습니다. 전화번호·상담 안내 컬렉션도 하나의 구조로 통합했습니다.

System

검색 화면에 공통 UI 기준을 만들었다

검색 디자인 시스템 구축에 참여해 검색 컬렉션의 공통 컴포넌트와 UI 기준을 정리했습니다. 통합검색 배너의 검수와 규격 가이드를 운영하며, 여러 서비스 부서의 요청이 공통 기준에 맞게 적용되도록 했습니다.

Operation

미룰 수 없는 날짜와 트래픽을 설계했다

올림픽·월드컵 같은 대형 스포츠 이벤트와 두 차례의 전국 선거 검색 특집을 출시했습니다. 실시간 개표처럼 사용자가 몰리는 핵심 정보의 구조를 설계하고, 정해진 일정에 맞춰 열었습니다.
