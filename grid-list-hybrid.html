Case 03 · KakaoTalk 더보기탭

그리드·리스트 혼합 UI 실험

앞선 리스트형 실험은 탐색량을 늘렸지만, 핵심 서비스가 첫 화면에서 밀려나며 서비스 클릭이 줄었습니다. 리스트의 탐색성은 살리고 매출을 만드는 서비스는 첫 화면에 고정하는 혼합안을 직접 테스트했고, 이 안이 다음 릴리즈의 공식 실험안이 됐습니다. 진행 중에 결과를 직접 집계해 손실이 레이아웃이 아니라 알림 표시 반응에 몰려 있다는 것을 찾았고, 실험을 흔들던 버그도 발견했습니다.

Problem

리스트로 바꾸자 핵심 서비스 클릭이 빠졌다

이전 실험에서 채택한 카테고리 리스트안은 광고 매출을 크게 늘렸지만, 서비스 클릭이 9% 줄고 선물하기를 거쳐 가는 거래액도 10% 가까이 줄었습니다. 같은 실험에서 선물하기를 리스트 1위에 놓자 하락폭이 3분의 1로 줄었습니다. 위치가 클릭을 결정한다는 신호였습니다.

Hypothesis

첫 화면에 보이는지가 클릭의 병목이다

목적이 있는 사용자는 원하는 서비스를 찾아가지만, 바로 보이지 않으면 이탈하는 사용자도 있다고 봤습니다. 그래서 매출 핵심 서비스는 첫 화면 그리드에 고정하고, 나머지는 카테고리 리스트로 더 많이 보여주는 혼합 구조를 설계했습니다.

판정 기준도 바꿨습니다. 이전 실험의 트레이드오프를 반영해, 성공지표가 유지만 되어도 성공으로 보고, 가드레일 둘 중 하나가 줄어도 총 매출이 유지되면 방어로 해석하기로 했습니다.

Design

그리드 구성만 바꾼 네 실험안

  • A · 4×3 그리드 + 리스트대조군과 같은 그리드 12칸을 유지하고 아이콘만 바꿔, 아이콘 변화의 영향만 따로 봅니다.
  • B · 4×2 그리드 + 리스트매출 상위 8개 서비스만 첫 화면에 고정합니다.
  • C · 5×2 그리드 + 리스트한 줄에 다섯 개를 두어 그리드 높이를 줄이고 리스트 도달을 늘립니다.
  • D · 4×2 그리드 + 리스트 중복 노출그리드의 서비스를 리스트에도 다시 보여줘 중복 노출의 효과를 봅니다.

실험군 아이콘은 홈 화면 다른 영역과의 일관성을 위해 그래픽 아이콘으로 통일하자는 디자인 검토 의견이 반영됐습니다.

Interim Result

모든 실험안에서 서비스 클릭이 줄었다

Android · 집행 첫 14일 · 사용자당 변화. 직접 만든 지표 조회 도구로 집계하고 데이터 분석팀의 중간 분석과 대조했습니다.

성공 조건을 만족한 실험안은 아직 없었습니다. 다만 가드레일은 네 안 모두 지켰고, 이전 실험보다 클릭 감소폭은 절반 가까이 줄었습니다.

Analysis

손실은 레이아웃이 아니라 알림 표시 반응에서 났다

알림이 없는 서비스 클릭은 모든 실험안에서 오히려 늘었습니다. 줄어든 것은 알림 점이 켜진 서비스로 돌아가는 클릭뿐이었습니다. 알림이 많았던 날일수록 손실이 커졌고, 알림이 적었던 날에는 실험안이 대조군을 넘기도 했습니다.

일별 추이를 직접 보다가 한 가지를 더 찾았습니다. iOS 일부 버전에서 실험안의 알림 점이 하단 탭에 표시되지 않고 있었습니다. 바로 공유했고, 클라이언트 핫픽스로 실험을 중단 없이 이어갔습니다. 최종 판정은 수정된 버전 기준으로 내리기로 했습니다.

Next

쓰던 서비스로 돌아가는 길을 다시 설계하고 있다

중간 결과를 받아, 중복 노출안을 기준으로 최근 사용 서비스 슬롯, 직접 고정하는 서비스, 카테고리 바로가기, 지금 챙길 일을 보여주는 맥락 카드 같은 보완안을 설계하고 있습니다. 그래픽 아이콘 위에서 알림 점이 덜 보이는지도 함께 점검합니다. 최종 결과는 실험 종료 후 업데이트합니다.
